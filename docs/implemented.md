# Что уже реализовано и настроено

## Качество кода и стиль
- **Spotless**: автоматическое форматирование кода. Запускается при сборке (`./gradlew spotlessCheck`) 
и может автоматически исправлять стиль (`./gradlew spotlessApply`).
- **Checkstyle**: статическая проверка стиля кода по правилам из `config/checkstyle/easy-checkstyle.xml`. 
**Стандартный чекстайл ругается, пришлось адаптировать более простую версию**.

## Архитектура и границы слоёв
- **ArchUnit**: тесты, которые не дают нарушить границы слоёв 
(например, контроллеры не могут напрямую импортировать репозитории). 
Нарушение правил сразу приводит к падению сборки.

## Тестирование
- **Flyway**: миграции БД управляются через Flyway.
- **JUnit 5 + Spring Boot Test**: тесты используют H2.

## CI/CD (GitHub Actions)
- Настроен пайплайн `CI`, который запускается на каждый `push` и `pull_request`.
- Выполняет полный цикл проверок: компиляция → Spotless → Checkstyle → тесты → ArchUnit.
- Отчёты (Checkstyle, тесты) генерируются в `build/reports/` и доступны локально и как артефакты в CI.
