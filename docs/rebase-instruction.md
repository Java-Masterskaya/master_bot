# Инструкция по работе с Git в IntelliJ IDEA (Feature Workflow)

### 1. Обновите локальную `main`
*   Переключитесь на ветку `main` (правый нижний угол IDEA).
*   Нажмите **Git | Pull** (или `Ctrl+T`) и подтвердите (нажмите **Pull**).
*   *Цель: получить самый свежий код с GitHub.*

### 2. Создайте новую ветку
*   Убедитесь, что вы на `main`.
*   Нажмите **Git | New Branch...** (или в правом нижнем углу на название ветки -> **New Branch**).
*   Введите имя по стандарту (например, `INF-04-...`), нажмите **Create**.
*   *Цель: работать над новой задачей изолированно, не ломая `main`.*

### 3. Напишите код и сделайте коммиты
*   Внесите изменения в файлы.
*   Нажмите **Commit** (или `Ctrl+K`), выберите нужные файлы, напишите сообщение и нажмите **Commit**.

### 4. Отправьте ветку на GitHub (первый раз)
*   Нажмите **Git | Push** (или `Ctrl+Shift+K`).
*   IDEA предложит создать удаленную ветку — соглашайтесь (нажмите **Push**).
*   *Цель: сохранить работу на удаленном сервере.*

### 5. Проверьте, нужен ли ребэйс (перед созданием Pull Request)
*   Откройте терминал (`Alt+F12`) и выполните: `git fetch`
*   Затем проверьте: `git log --oneline HEAD..origin/main`
*   **Если вывод пустой** — ребэйс не нужен, переходите к шагу 7.
*   **Если есть строки** — ребэйс нужен, переходите к шагу 6.

### 6. Сделайте ребэйс (если нужно)
*   Убедитесь, что вы на своей рабочей ветке.
*   Нажмите **Git | Rebase**.
*   В качестве целевой ветки выберите **`origin/main`** (не локальную `main`!).
*   Нажмите **Rebase**. Если будут конфликты — разрешите их и нажмите **Continue Rebase**.
*   Отправьте изменения на GitHub с принудительным обновлением: **Git | Push** -> стрелочка вниз рядом с кнопкой Push -> **Force Push** (или в терминале `git push --force-with-lease`).

### 7. Создайте Pull Request (PR) на GitHub
*   Перейдите на сайт GitHub в ваш репозиторий.
*   Нажмите **Compare & pull request** (или вкладка **Pull requests** -> **New pull request**).
*   Убедитесь, что мерж идет из вашей ветки в `main`.
*   Напишите заголовок и описание, нажмите **Create pull request**.

### 8. Смержите PR и обновите `main`
*   После проверки (или если вы работаете сами) нажмите **Merge pull request** на GitHub.
*   Переключитесь в IDEA на локальную `main`.
*   Сделайте **Git | Pull**, чтобы подтянуть этот мерж (как на вашем последнем скриншоте).

*(Повторяйте с шага 2 для каждой новой задачи).*
